# Switch Library

[English](README.md) · **Українська**

Нативний застосунок для робочого столу, який упорядковує архіви ігор Nintendo Switch. Переглядайте колекцію, перевіряйте відомі оновлення та керуйте завантаженнями в одному місці.

Застосунок використовує зовнішні каталоги. Сам Switch Library не розповсюджує релізи ігор.

У цьому репозиторії публікуються релізи застосунку та приймаються звіти про помилки.

[Завантажити релізи](https://github.com/XpycT/switch-library-releases/releases) · [Повідомити про помилку](https://github.com/XpycT/switch-library-releases/issues/new?template=bug_report.md) · [Запропонувати функцію](https://github.com/XpycT/switch-library-releases/issues/new?template=feature_request.md)

## Можливості

- Сканує архіви NSP, NSZ, NSX, XCI та XCZ у кількох теках бібліотеки, включно з вкладеними теками.
- Групує базові ігри, оновлення та DLC за Title ID.
- Показує вашу бібліотеку й зовнішні каталоги з обкладинками, скриншотами, описами ігор і деревом локальних файлів. Теку гри можна відкрити у файловому менеджері. Дозволяє шукати за назвою, фільтрувати за жанрами та сортувати за назвою, розміром або датою виходу.
- Порівнює відомі локальні версії з titledb, щоб знайти доступні оновлення.
- Показує встановлені й відсутні DLC та доступні оновлення в одному списку. Непотрібні записи можна ігнорувати й згодом повернути до списку.
- Показує мови гри й озвучення, якщо ці відомості доступні. Мови встановленої гри визначає за найновішим локальним оновленням, метадані якого вдалося прочитати, або за базовою грою.
- Дозволяє вибирати серед доступних релізів гри й порівнювати їхні файли з локальною копією перед завантаженням.
- Дозволяє вибрати теку бібліотеки для кожного завантаження. Перед підтвердженням показує потрібне й вільне місце; теки, де місця бракує, недоступні для вибору.
- Дозволяє додавати ігри до черги завантажень. Можна призупиняти, продовжувати чи скасовувати завантаження зі збереженням файлів; видалення файлів потребує окремого підтвердження.
- Зберігає доступ до кешованих відомостей про ігри, коли каталог або диск бібліотеки недоступний.
- Дозволяє вибрати тему оформлення та підтримує 9 мов інтерфейсу.

Сканування працює без ключів консолі. За бажанням у налаштуваннях можна вибрати файл або теку з ключами та ввімкнути їх використання, щоб читати назви, мови й версії з метаданих архівів. Якщо прочитати метадані не вдалося, сканер використовує назви файлів. Використання ключів можна вимкнути зі збереженням вибраного шляху.

Невідомі локальні версії залишаються невідомими; новіша версія в titledb не гарантує, що завантаження з каталогу містить саме її.

## Завантаження та встановлення

Відкрийте [Релізи](https://github.com/XpycT/switch-library-releases/releases) і виберіть файл для своєї платформи. Якщо релізів немає, публічні завантаження ще не опубліковано. Назви файлів можуть відрізнятися; на сторінці кожного релізу вказано, які файли він містить.

| Платформа | Файл | Примітки |
| --- | --- | --- |
| macOS / Apple Silicon | `Switch-Library-macos-arm64.zip` | Для Mac на M-серії; не запускається на Intel Mac |
| Windows / x64 | `Switch-Library-windows-x64.zip` | ZIP з виконуваним файлом |
| Linux / x86_64 | `Switch-Library-linux-x86_64.AppImage` | Зібрано на Ubuntu 22.04; потрібен glibc 2.35 або новіший |

Роботу застосунку перевірено на macOS. Збірки для Windows і Linux не тестували на реальному обладнанні, тож наявність збірки не означає, що вона працює на будь-якій конфігурації.

### macOS

Розпакуйте ZIP, перенесіть **Switch Library.app** у теку **Програми** і відкрийте застосунок.

Поточні збірки не підписані Developer ID і не нотаризовані. Якщо macOS блокує програму як таку, що походить від невідомого розробника, скористайтеся [інструкцією Apple для відкриття програм, яким ви довіряєте](https://support.apple.com/en-us/102445): спершу спробуйте відкрити застосунок, а потім виберіть **Системні налаштування → Конфіденційність і безпека → Відкрити все одно**, якщо такий пункт з'явиться.

### Windows

Розпакуйте ZIP і запустіть `switch-library.exe`. Інсталятор не потрібен. Виконуваний файл не має підпису, тож Windows може показати попередження про репутацію.

### Linux

Зробіть завантажений AppImage виконуваним і запустіть його:

```sh
chmod +x Switch-Library-linux-x86_64.AppImage
./Switch-Library-linux-x86_64.AppImage
```

Якщо FUSE недоступний, розпакуйте AppImage й запустіть так:

```sh
./Switch-Library-linux-x86_64.AppImage --appimage-extract-and-run
```

Потрібні сеанс Wayland або X11, робочі драйвери Vulkan і портал робочого столу з бекендом, що відповідає вашому середовищу. AppImage містить бібліотеки застосунку, але не замінює графічні драйвери й не працює на кожному дистрибутиві Linux.

## Початок роботи

1. Відкрийте застосунок і виберіть теку з архівами ігор.
2. Дочекайтеся завершення сканування, потім перегляньте колекцію та перевірте відомі оновлення.
3. Відкрийте «Налаштування», щоб додати чи прибрати теки бібліотеки, змінити мову або тему, налаштувати джерела каталогу чи використання ключів консолі.

Додавання чи вилучення тек бібліотеки не переносить наявні файли. Завантаження в черзі зберігають вибрані для них теки. Сканування ніколи не записує в архіви. Заміна чи видалення файлів відбувається лише після вашого підтвердження.

## Каталоги та завантаження ігор

У налаштуваннях можна додавати зовнішні каталоги, редагувати їхні адреси, вмикати чи вимикати та змінювати порядок. Каталоги вище у списку мають пріоритет. Видалення каталогу не зачіпає ваші файли й чергу завантажень. Застосунком можна користуватися й лише з локальною бібліотекою.

Якщо гра має кілька релізів, виберіть потрібний на її сторінці, щоб переглянути файли або завантажити його. Виберіть теку призначення й підтвердьте завантаження. Застосунок позначає теки, які вже містять гру, щоб ви бачили, коли завантажуєте ще одну копію. Перед заміною локальних файлів перегляньте порівняння й підтвердьте оновлення. Застосунок готує завантаження в тимчасовій теці, для якої потрібне додаткове місце на диску. Локальні файли, яких немає у вибраному завантаженні, залишаються на диску.

## Оновлення застосунку

Виберіть **Перевірити оновлення** в меню застосунку, щоб перевірити наявність нової версії Switch Library. Коли оновлення з'явиться, виберіть його в рядку стану, а потім натисніть **Перезапустити й оновити**, коли будете готові. Якщо автоматичне оновлення недоступне для вашої збірки, завантажте нову версію зі сторінки [Релізи](https://github.com/XpycT/switch-library-releases/releases).

## Помилки та побажання

Перш ніж створювати новий issue, пошукайте серед [уже відкритих](https://github.com/XpycT/switch-library-releases/issues). Для збоїв використовуйте шаблон звіту про помилку, а для пропозицій оберіть шаблон запиту функції.

Додайте версію застосунку, операційну систему, архітектуру процесора та кроки для відтворення. Приберіть з логів і скриншотів особисті шляхи, облікові дані та приватні посилання на завантаження. Не додавайте архіви ігор і ключі консолі.
